Put your own documents here as .txt or .md files, one file per document. The file name (without the extension) is the document name used in the questions file.

Use public material you own or wrote: your own project READMEs, your paper, notes you are free to share. Do not use company documents.

Aim for 3 to 6 documents, a few hundred words each or more. Short, factual documents with specific numbers, names and rules make the best test material.
